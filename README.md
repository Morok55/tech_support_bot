# 🤖 Tech Support Bot

Телеграм-бот для обработки обращений пользователей и управления FAQ.  
Реализован на **Python** с использованием библиотеки **pyTelegramBotAPI** и базы данных **SQLite**.

---

## 🚀 Возможности
- Пользовательская часть:
  - Отправка жалобы или вопроса в техподдержку
  - Возможность прикрепить изображение
  - Просмотр истории обращений
  - Просмотр ответов администратора
  - Доступ к списку часто задаваемых вопросов (FAQ)

- Админ-панель:
  - Ответ на новые обращения
  - Просмотр списка активных обращений
  - Управление FAQ (добавление и удаление вопросов/ответов)

## ⚙️ Установка и запуск

1. Склонируй репозиторий:
   ```bash
   git clone https://github.com/Morok55/tech_support_bot.git
   cd tech_support_bot
   ```

2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

   (Если файла `requirements.txt` нет, установи вручную:  
   ```bash
   pip install pyTelegramBotAPI python-dotenv
   ```)

3. Создай файл `.env` и добавь туда токен своего бота:
   ```
   TELEGRAM_TOKEN=ваш_токен
   ```

4. Запусти бота:
   ```bash
   python tech_support_bot.py
   ```
